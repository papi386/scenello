## Invocation decisions and fallbacks

For substantial visual direction, read an available frontend/art-direction skill before committing composition. If absent, use Scenello's art-direction guide and inspect a relevant authorized reference. For coordinated scroll/pin choreography, read installed GSAP scroll/timeline guidance when choosing that library; otherwise implement the same progress contract with the existing stack. Never add a library solely to claim tool usage.

Use an image-generation capability only when existing licensed assets cannot satisfy the chosen direction; validate anatomy/materials and retain provenance. Without it, choose an authorized asset route and disclose any fidelity limit. Use a component MCP for a concrete missing interface pattern, inspect its license and adapt it; skip retrieval when native elements already solve the task. Use an available 3D/Blender capability only when geometry or authored cameras are essential and a bounded prototype proves feasibility.

Use available browser automation to inspect initial, intermediate and usable states; use traces when a measured performance defect needs diagnosis. If browser access is unavailable, provide a runnable implementation with verification explicitly pending, never claim a visual pass. Optional tools are not bundled dependencies. Do not install or connect them without the required authorization.
