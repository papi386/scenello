# A source ledger before a style library

Keep source media, filenames, identifying URLs, hashes and private project history outside the distributable repository. Run `scripts/intake.py` only on an authorized local ZIP and choose an external private output directory. It hashes bounded members without extracting or running them. Nested archives and active files require separate review, never automatic execution. Limits are documented in security.md.

An inventory proves enumeration and byte hashing, not semantic inspection or rights. Give every entry a disposition and review depth. Archive identity requires provenance; a similarly named backup is not the original reference. Preserve unresolved inputs visibly.

## Source dispositions

* PUBLIC_REUSABLE: explicit compatible redistribution right, license/provenance retained.
* PUBLIC_LINK_ONLY: cite a public source; do not bundle its media.
* SAFE_DERIVATION: independent explanatory technique and original artwork, reviewed for identifiers and copying.
* PRIVATE_REFERENCE_ONLY: useful privately, no public reproduction.
* OUT_OF_SCOPE: promotional video production, unrelated applications or duplicate deliverables.
* UNVERIFIED: insufficient inspection, provenance or rights.
* REJECTED_UNSAFE: path/link/bomb or other failed safety checks.

A domain or social platform is not a rights decision. Facebook-origin references are relevant when authorized. If only a login-gated URL exists, mark it inaccessible; do not bypass access controls. Do not replace unavailable source analysis with invented claims.

## Local video analysis

Inspect metadata first: duration, dimensions, rotation, frame rate, audio presence and file size. Produce a bounded low-resolution contact sheet using a trusted installed decoder with limited threads; retain it privately. Read key frames before, during and after each transition. Scrub motion around direction changes: sparse frames cannot establish timing or easing. Do not judge soundtrack quality without listening, and do not import audio into a web-design package.

For each technique write: creative objective; independently worded visual description; numbered temporal beats; coordinate frame; camera/object motions; scroll/pointer trigger; continuous handoff; implementation choices; mobile recomposition; reduced motion; performance risks; deterministic validation. Include actual uncertainty. A useful guide must work without the original clip.

## Original reconstruction

Create a 3–6-frame SVG/code storyboard with focal points, direction arrows and normalized progress. It explains a mechanism, not a frame-for-frame copy. Label it “original explanatory reconstruction”, with no implication it is an original source screenshot. If external image generation is appropriate, submit only generic sanitized text after checking tool/privacy policy; no confidential media. Record model/tool/date, prompt provenance and resulting usage terms. No image provider is required for Scenello core.

Public catalog fields: stable ID, technique, purpose, guide path, original demo, allowed public citations, implementation choices, dependencies, limitations and validation. Keep private source mapping in the private ledger only.
