# Synchronized product and surface identity

Independent technical reconstruction from a locally inspected reference. Source media, platform identities, brands and frame captures remain private. Approximate times describe the recording, which may start mid-page or loop; they are not a specification of source code or easing.

## Creative objective
Use a product variant change to reorganize the whole visual world without losing the product identity.

## Visual description
A central handheld object changes surface artwork and surrounding colour together, while a separate product grid and navigation remain part of the website.

## Temporal sequence and key moments
0–3s: changing hero identity; 3–7s: catalogue and product options; 7–11s: return to hero; 11–16s: successive horizontal variant passages; final seconds loop.

## Motion and camera
The object keeps a recognizable screen position while its treatment and environment change. The recording does not prove a live material swap versus pre-rendered imagery.

## Implementation
Use one canonical shape/perspective and explicitly register variant plates or material maps. Animate the outgoing/incoming object in width with a modest perspective turn only if the source assets support it. Synchronize backdrop, label and selection state in one timeline; do not rely on a diagonal wipe to conceal mismatched anatomy/shape.

## Interaction
If the brief asks for scroll, derive variant state from segment progress. A real option selector may remain as accessible direct navigation; it must not be the only animation trigger.

## Responsive adaptation
Keep the product large enough on mobile and preserve one stable copy zone. Reduce decorative pattern density rather than shrinking the focal object.

## Accessibility
Expose current option and ordinary product links. Reduced motion changes variants without a large spatial passage.

## Performance
Preload only nearby variants, decode before reveal, avoid four full-resolution transparent layers at once and release distant GPU textures.

## Validation
Check matching silhouettes, label legibility, reverse/fast scroll, disabled JS, real selection state and no text/image overlap.
