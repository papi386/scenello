# Design vocabulary as a selection tool

Independent technical reconstruction from a locally inspected reference. Source media, platform identities, brands and frame captures remain private. Approximate times describe the recording, which may start mid-page or loop; they are not a specification of source code or easing.

## Creative objective
Choose a visual language for the product rather than copying a style label.

## Visual description
A design-education recording cycles through poster examples and style names. It is taxonomy evidence, not a cinematic interaction or a license to reuse those artworks.

## Temporal sequence and key moments
The approximately 21-second capture loops a sequence including abstract, grunge, vintage, brutalist, typographic, human-action, glass-like, cyberpunk, minimal, surreal, Y2K, psychedelic, Swiss, luxury and Bauhaus examples. The loop starts mid-list; this is not a historical classification.

## Motion and camera
Examples are shown as presentation slides. No scroll, camera or underlying website behavior can be inferred from them.

## Implementation
Translate each candidate into operational choices: grid, type hierarchy, surface/material, image direction, interaction feedback and reading density. Compare two or three against the subject and actual content. Swiss structure can improve information hierarchy; geometric Bauhaus language can support an object system; editorial luxury needs excellent imagery and restraint, not just black/gold.

## Interaction
Keep style selection an art-direction decision unless the product actually needs a user selector. Reuse a selector mechanism for real categories or experience history, not gratuitous theme switches.

## Responsive adaptation
Re-compose hierarchy, headline wrapping and media placement for mobile. A poster composition is not automatically a usable responsive page.

## Accessibility
Preserve contrast, focus, reflow and semantic order in every selected language. A deliberate rough aesthetic does not justify inaccessible controls.

## Performance
Limit font families/weights and obtain proper font rights. Texture and glass effects need measured paint/memory budgets.

## Validation
Test real long headings, content density, small displays and functional destinations. Validate the selected style throughout later sections, not only in the hero.
