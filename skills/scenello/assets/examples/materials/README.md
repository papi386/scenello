# Materials — original working study

Serve the parent examples directory with a loopback static server. No build, download or account.

Design: cobalt editorial archive, original material swatches, diagonal fan and functional filtering. Procedural artwork and text are original, MIT; font software has its separate OFL license. No captured reference imagery. Small same-origin, preloaded Scenello UI fonts preserve the UI typographic direction; the renamed Selawik derivative is OFL-1.1 with its license in ../fonts/. No external font service is used.

Technique mapping: SCN-02, SCN-03, SCN-07, SCN-08. Scroll is native and reversible; skip links lead to actual content. Reduced motion and missing JS preserve a normal reading path. Only transforms and opacity change during the scene; listeners are removed on pagehide.

See repository docs/verification.md for actual responsive checks, screenshots and repeated performance measurements, plus testing limitations. An installed standalone skill does not contain that changing maintainer report; reproduce the technique tests in your own project. CSS material studies are symbolic illustrations, not photorealistic product images.
