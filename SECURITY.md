# Security

No telemetry, remote service, account, secret or automatic installation is required by Scenello. The utilities operate on explicitly selected local inputs. Read their source before running them. ZIP inventory never executes members or recursively opens archives; limits and residual risk are documented in the security reference.

Do not put private recordings or credentials in public issues. Report vulnerabilities using GitHub Private Vulnerability Reporting once enabled in the repository's Security settings. Do not disclose exploitable details in public issues. If that feature is unavailable, contact the project maintainer privately through a verified channel.

The release scanner is a heuristic gate, not a malware detector, rights opinion or complete secret scanner. Review the final payload and Git history. A source URL is not a redistribution license. This package does not weaken host sandbox or approval policies.
