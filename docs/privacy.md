# Privacy information for owner review

The distributed Scenello instructions and optional local helpers contain no telemetry, server, hosted account or automatic upload. Installation copies files into an explicitly chosen project. Optional intake, audit and validation tools write local outputs at caller-selected paths; these can contain project information and remain private unless the user chooses to share them.

A user's coding host and optional connected services have their own policies. The skill requires authorization before sending private assets to external tools. It does not set a universal retention period for the user's own local files; users control their retention and deletion.

Before public submission the owner must provide the verified publisher identity, contact and a published policy reflecting the final distribution. This reviewed package document is not a claim that a public policy URL already exists.
